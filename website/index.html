Gold vs USD

Attach the EA to your broker’s XAUUSD or XAUUSDm chart (any suffix that still contains XAU and USD in the symbol name is recognised).

  • InpTradeGoldOnly — blocks attach on non-gold pairs (disable if you intentionally repurpose the code).
  • InpApplyGoldPresets — raises minimum spread / slippage / liquidity tolerances suitable for volatile metals.
  • Defaults use wider spread and point tolerances; always tune InpMaxSpreadPoints to your broker’s typical XAU spread.

Quick checklist

  1. Use H1 or M15 preview, attach EA to XAUUSD.
  2. Enable Algo Trading; allow WebRequest only if you add news APIs later.
  3. Backtest with your broker’s gold contract specs and commissions.
  4. VPS + low latency recommended for live execution.

Install (one folder)

  1. Copy the entire AFRICAD_QUANT_001 folder into MQL5/Experts/ so the EA path is MQL5/Experts/AFRICAD_QUANT_001/… — not only the .mq5 file in Experts/ root (that breaks #include).
  2. Open main995Gold.mq5 or MainEA.mq5 from inside that subfolder and compile (F7).
  3. Drag the EA onto an XAUUSD chart; confirm inputs and session UTC alignment.
  4. Forward-test / optimize on your broker’s gold symbol; adjust spread and ATR multipliers.

This site is static HTML — open website/index.html in a browser, or host the website/ folder on any static host (GitHub Pages, Netlify, S3, etc.).
